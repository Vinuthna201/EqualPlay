# EqualPlay
#  Gender Sensitivity & Awareness Game

An interactive AI-powered web game that promotes gender sensitivity through real-world scenarios, character-based storytelling, and personalized learning.

## 🚀 Live Demo

 [Play the MVP on Vercel]([https://your-project-name.vercel.app](https://equal-play.vercel.app/))

## 💡 Features

- Character Selection (Boy, Girl, Teacher, Parent)
- AI-Generated Scenarios (via Cohere API)
- Voice-Based Responses
- Scoring System & Progress Bar
- Leaderboard and Social Sharing
- Career Tools: Internship Finder, Mentorship, Courses
- Login/Signup Authentication with JWT
- Responsive UI with smooth animations

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Integration:** Cohere API
- **Speech Recognition:** Web Speech API
- **Deployment:** Vercel
